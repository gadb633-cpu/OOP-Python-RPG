## Game Rules

It is a game of one user against the computer. 
the user enters to the room and fights with the monster until victory.
The first to attack is the winner. The attacker is chosen based on the sum of the higher Agility and Luck values.

## How to Run

1. Clone the repository.
2. Open the project in your computer.
3. Run the `main.py` file.

## How to play
Enter your name in the 'config' file on PLAYER_NAME
You can update the various values ​​for a monster and a player in a config file, but the values ​​for health, strength, agility, and luck must be numeric values.
